One hilarious line that lands entirely on its own: the password manager that forgot the one password it exists to remember — then suggested resetting it with that same password.

> My password manager forgot my password, then suggested I reset it with the password I'd forgotten.

## How it works

`main.py` (Python 3 standard library only) writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line, no title, no setup, no explanation.

```sh
python3 main.py
```
